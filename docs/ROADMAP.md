# Roadmap

The work is split into phases. Each phase delivers a usable set of tools.

| Phase | Content | Status |
|---|---|---|
| 0 | Solution scaffold, tray host, hotkey service, settings, module interface, CI (Windows runner) | Done |
| 1 | Tray menu, Apps Center, Fast Boot, Awake, Always On Top, Light Switch, Autostart | Done |
| 2 | Quick search (global shortcut) including the file indexer | Next |
| 3 | FancyZones, Workspaces, remote window compatibility | Planned |
| 4 | Files: PowerRename, Image Resizer, File Locksmith, file conversion, Peek, New+ | Planned |
| 5 | Input: Keyboard Manager, Mouse Utilities, Quick Accent | Planned |
| 6 | Text and developer tools: Advanced Paste, Text Extractor, Color Picker, Screen Ruler, Hosts editor, Registry Preview, Environment Variables, Shortcut Guide | Planned |
| 7 | Personalization: wallpaper library, animated wallpapers, desktop widgets | Planned |
| 8 | Remaining tools: ZoomIt, Crop And Lock, Mouse Without Borders, Command Not Found, file previewers | Planned |

Cross-cutting items: a settings window (runs only on demand), a logo and design system, an installer,
and code signing so Windows does not block the program on other computers.
